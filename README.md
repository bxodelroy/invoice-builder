# Invoice Builder

A React-based Invoice Builder application that allows users to:

- Add invoice items
- Delete invoice items
- Calculate subtotal, tax, and total automatically
- Generate and download invoices as PDF
- Enter client and invoice details

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- html2pdf.js
